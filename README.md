# 生命保険料控除いくら？（seiho-ikura）

1年に払った生命保険料・医療保険（介護医療保険料）・個人年金保険料と入った年（新契約・旧契約）の場面を読んで、生命保険料控除の額を当てる1日5問の学習ゲーム。正解したら「どの決まり？」（新契約の表・旧契約の表・新と旧の両方・23歳未満の扶養親族・3つの合計）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/seiho-ikura/>

- 答えは、国税庁タックスアンサーの表（2012年1月1日以後の新契約は2万円まで全額・8万円超は4万円。2011年以前の旧契約は2.5万円まで全額・10万円超は5万円。新と旧の両方は合わせて4万円まで。23歳未満の扶養親族がいると新生命保険料は最高6万円。一般・介護医療・個人年金の合計は12万円まで）から出しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）。
  - No.1140 生命保険料控除 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1140.htm>
- 金額は令和8年分の決まりです（23歳未満の扶養親族の特例を含む）。保険料は、その年に払った額から剰余金・割戻金を引いた額です。税額・保険期間5年未満の貯蓄保険などの対象外・住民税・申告の手続きは出しません。人と金額はつくりものです。
- このゲームは生命保険料控除のしくみを知る練習です。税の相談の代わりではありません。実際の控除の額は、国税庁の資料や税務署で確かめてください。
